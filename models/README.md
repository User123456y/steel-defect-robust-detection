# 模型

`best.pt` 为 V1 对比度增强 seed42 的六类 YOLO11n 推理模型，推荐输入 320、置信度 0.4、NMS IoU 0.7。阈值来自历史验证集校准，不是针对公开封装重新搜索。

公开封装仅将训练参数和模型属性中的数据、项目、保存目录及初始化权重路径改为相对路径，并删除空 Git 元数据、规范训练运行名称。许可证、模型架构、类别、数值参数及训练历史保留。公开文件哈希与历史文件哈希不同；二者见 `verification.json`，推理配置绑定公开文件哈希。历史结果中的原 SHA 仍表示原工件。

已核验全部 499 个 state_dict 张量逐位相同，并在两张合成图片及两张验证图片（含非空检测）上对比 CPU 检测输出。另以固定种子随机输入逐位比对 NMS 前原始输出（1×10×2100），最大绝对误差为 0。该检查只证明所测案例的封装等价性，不是重新训练、测试集评估或 GPU 性能认证。

初始化权重请从 [Ultralytics 官方 v8.3.0 assets](https://github.com/ultralytics/assets/releases/tag/v8.3.0) 下载 `yolo11n.pt` 至本目录，遵守其 AGPL-3.0 许可。ONNX 与 TensorRT 引擎请在部署环境用脚本生成。
