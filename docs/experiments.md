# 实验报告

## 统计口径

除明确标注“百分点”的差值外，JSON和CSV中的比例通常位于0至1。mAP50–95为IoU 0.50至0.95的平均AP。固定阈值F1按2TP/(2TP+FP+FN)计算；TP匹配使用IoU0.5。同类重复预测计为FP。模型选择和阈值校准使用验证集，最终测试集为270张。

## V1：对比度增强

baseline与control分别运行种子42、43、44。干净验证的三种子平均AP50–95差值为+0.03875个百分点，增益不稳定。不能将单次较优模型解释为稳定的总体提升。

同一PNG/CPU路径的合成扰动实验中，clean差值为+0.0252个百分点，对比度α=0.75为+1.5923个百分点、α=0.5为+6.3494个百分点（两档均3/3种子为正）；α=0.5时AP50–95从34.6158%提高至40.9653%。Gaussian σ=10为−1.2544个百分点（2负1正）。两条clean结果属于不同输入路径，不能互换。

最终test：mAP50 75.6021%、mAP50–95 44.8650%；置信度0.4、NMS IoU0.7、匹配IoU0.5下TP408、FP112、FN204，共612个GT；P78.4615%、R66.6667%、F1 72.0848%。龟裂固定阈值召回仅8.9109%，类别表现明显不均衡。

## V2：关闭mosaic

三种子平均AP50–95提升0.4738个百分点，未达到预设+1个百分点门限。因此保留V1默认权重。原始逐轮训练指标保存在`../results/02_训练记录`，三种子汇总及配对差值保存在`../results/01_三随机种子对比`。

## V3：GPU后端

设备为RTX4090，batch1、320×320固定方形输入，关闭TF32。每个后端每轮预热50次、正式测量538次，对269张验证图重复测量。主顺序与反顺序均独立测量。

主顺序请求P50：PyTorch FP32 8.081ms、TensorRT FP32 3.529ms、TensorRT FP16 3.177ms；反顺序分别7.875ms、3.640ms、3.419ms。FP16请求加速比分别2.54倍和2.30倍。计时包含解码、输入适配、传输、前向、NMS及CPU结果转换，排除模型加载和结果序列化，不能直接解释为产线吞吐率。

同一GPU评价路径中，FP32与PyTorch AP一致；FP16 AP50–95由42.4612%降至42.4061%，降低0.0551个百分点。固定0.4的TP/FP/FN为390/123/222。该路径使用固定方形LetterBox和统一后处理，其AP不能直接与历史最终test或其他验证路径混比。

进程显存统计约496/512/510MiB，并未显示显存降低。主反顺序四组候选均通过既定精度/数值门限。公开仓库保留历史性能摘要；不包含原始张量和逐图标注，无法仅凭本仓库完整复算原GPU误差结论。

## 外部跨类别框定位

GC10-DET下载发布为2300图，8张空标注排除评分；2292张有效图含3563个GT。固定原模型与阈值，六类预测经原class-aware NMS后合并为foreground，十类外部GT也仅在匹配时合并；不增加二次NMS，不声称类别语义等价。

TP61、FP961、FN3502，预测1022框，P5.9687%、R1.7120%、F1 2.6609%。这是未适配的跨类别定位压力测试，不能称为六类识别准确率。未匹配预测是相对于现有标注的未匹配框，未必是真实现场误报；8张空标注没有正常样本真实性保证。文件/像素/感知哈希筛查也不能证明零同源或零预训练泄漏。

公开仓库仅保留`../results/07_外部跨类别定位/定位指标.json`聚合数值，不分发原图、标注与逐图派生图。


## 历史记录与公开版本

`configs/contrast_proposal.json` 是训练前冻结的方法假设，状态和来源摘要保留为历史记录；其单种子计划随后扩展为三种子重复实验。文件中的历史报告路径用于说明原始证据身份，不是公开仓库运行依赖。公开数值不因代码路径调整或权重重新封装而改写。

公开版本已通过 64 项合成夹具单元测试、CPU 单图命令行推理和验证集 269 条身份摘要检查。模型的参数与原始前向输出等价检查见 `../models/verification.json`；这些检查不构成重新训练、最终测试集复测或 GPU 性能复测。
